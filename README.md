# Portfolio de Videojuegos Web 🎮

**Desarrollado por: Denis Medrano Carrasco**

¡Bienvenido/a a mi portafolio de proyectos de desarrollo web interactivo! Soy estudiante de Ingeniería de Sistemas y este repositorio reúne una colección de 6 juegos desarrollados con tecnologías web nativas (HTML5, CSS3 y JavaScript). Las mecánicas abarcan desde simulaciones financieras y entornos 3D, hasta lógica matemática y novelas visuales narrativas.

---

## 🛠️ Tecnologías y Habilidades

- **Lenguajes:** JavaScript (ES6+), HTML5 semántico, CSS3 avanzado.
- **Renderizado y Gráficos:** HTML5 Canvas (2D Context), Three.js (WebGL), animaciones CSS por fotogramas y transformaciones espaciales.
- **Arquitectura de Software:** Bucles de juego (`requestAnimationFrame`), máquinas de estado, gestión de físicas personalizadas y detección de colisiones.
- **Diseño UI/UX:** Interfaces adaptativas (Responsive Design), HUDs dinámicos y retroalimentación visual en tiempo real.

## 💻 Instrucciones de Ejecución

Todos los juegos son **100% Client-Side**. No requieren instalación de dependencias, Node.js ni bases de datos.
1. Clona este repositorio: `git clone [url-del-repo]`
2. Abre cualquiera de los archivos `index.html` de cada carpeta directamente en tu navegador (Chrome, Firefox, Edge o Safari).
