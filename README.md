## 🎯 Sobre el Proyecto

Este repositorio presenta mi **portafolio de desarrollo de videojuegos web**, creado como parte de mi formación en **Ingeniería de Sistemas**.

El proyecto reúne una colección de **6 videojuegos interactivos**, desarrollados utilizando tecnologías web modernas y recursos nativos del navegador.

Cada proyecto aborda diferentes conceptos de programación, diseño, interacción y desarrollo de videojuegos, incluyendo **simulación, lógica matemática, entornos 3D, narrativa interactiva, gestión de recursos y mecánicas arcade**.

El objetivo principal es demostrar la aplicación práctica de conocimientos de programación y desarrollo web mediante experiencias interactivas completamente funcionales.
